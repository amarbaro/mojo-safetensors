# mojo-safetensors v0.1.0

**Released:** 2026-10-21 · **Commit:** the one tagged v0.1.0 · **Previous:** first release

## What it does

Read and write safetensors files and Hugging Face checkpoint directories from Mojo.

## Highlights

- Zero copy: the file is mmapped, a tensor's data is a span into it.
- Accepts and rejects exactly what huggingface/safetensors 0.6.2 does on 42 test files; writes its layout.
- Lists a 2,707-tensor shard in 2 ms (reference 505 ms; `scripts/bench.sh`).

## Changes

First public release, no earlier version.

## Verified

| Check | Result |
|---|---|
| `scripts/check.sh`: 42 files, 18 rewrites, 5 directories, 50k-tensor time | `PASS all` |
| `scripts/selfcheck.sh`: 6 mutants | all rejected |
| three real checkpoints (deepseek-ocr-2, humains-junior, a kandinsky text encoder) | listings identical |

## Known limits

- Linux only. Read-only mapping; Writer keeps all data in memory until save.
- Files with 2+ metadata keys match the reference in content, not bytes (the reference uses hash order).
- F6 writing is checked by read-back only; the reference cannot write F6.
